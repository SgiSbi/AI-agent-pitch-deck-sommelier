# ИИ-ассистент для автоматизированного анализа стартапа на венчурную инвестопригодность на основе презентации проекта

## Инструкция по запуску 

На действительный момент приложение состоит лишь из скрипта для автоматического получения скриншотов презентации. 
Для работы необходимо следующее взаимодействие с директорией "/backend":

1. Смена рабочей директории
```cmd
cd путь\к\проекту\backend
```
2. Активация виртуального окружения
```cmd
.venv\Scripts\activate
```
3. Установка зависимостей
```cmd
pip install -r requirements.txt
```
4. Подготовьте входной файл презентации, переименовав его в input.pdf и скопировав в директорию \tmp
5. Запустите выполнение скрипта test.py
```cmd
python test.py
```
6. Подготовленные к отправке в LLM слайды будут находится в директории \tmp\slides


## Структура проекта

Ai-agent/     
│    
├── backend/                         # Исходный код серверной части приложения        
│   └── requirements.txt         # Зависимости Python    
│    
├── data/                               # Исходные данные и промежуточные результаты

│   └── annotations/               # Ручные/автоматические описания слайдов (JSON, TXT, CSV)    
│     
├── frontend/                         # Код пользовательской части приложения
│     
├── prompts/                         # Промпты для LLM     	
│     
├── reports/                           # Готовые отчёты    
│    
├── docs/                               # Документация проекта     
├── .gitignore                         # Игнорирование временных/системных файлов    
├── README.md                     # Описание проекта    
└── requirements.txt              # Зависимости Python
