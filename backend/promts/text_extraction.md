Извлеки фактический контент с каждого слайда презентации. Без оценок и выводов.

## Формат (строго, для каждого слайда по порядку)

```
Слайд #N:
— Текст: [весь читаемый текст: заголовки, списки, подписи, футеры]
— Изображения:
  - [Тип]: [описание по правилам ниже]
— Примечания: [только неочевидные элементы; иначе строку не выводить]
```

## Правила изображений

**Графики, диаграммы, таблицы, схемы** — обязательно:
- тип (столбчатая, линейная, pie и т.д.);
- все числа, оси, легенда;
- краткий вывод из визуала (только описательный: «рост с 2023 по 2025»).

**UI / продукт** — ключевые блоки и функции.

**Декоративное** — одна строка: `Декоративное изображение: [тема]` или `Логотипы партнёров (без контекста)`.

## Текст

- Без сокращений; сохранять иерархию заголовков.
- Нечитаемо → `[Текст не поддаётся распознаванию]`.
- Не объединять слайды; не пропускать слайды.

## Запрещено

- Emoji, markdown-заголовки `#`, блоки ```.
- Собственные оценки продукта.
- Вводные фразы перед `Слайд #1`.

Первая строка ответа: `Слайд #1:`
